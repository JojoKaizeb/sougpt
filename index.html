01 / Fundamentals

Bagaimana Large Language Model bekerja?

Large Language Model atau LLM adalah model yang dilatih menggunakan jumlah teks sangat besar untuk mempelajari pola hubungan antara token, kata, kalimat, dan konteks.

Model tidak sekadar mencari jawaban dari database. Model memprediksi token berikutnya berdasarkan konteks percakapan, instruksi, pola yang dipelajari, dan berbagai lapisan pemrosesan lainnya.

Karena prosesnya sangat bergantung pada konteks, perubahan kecil pada susunan prompt dapat menghasilkan respons yang berbeda.
02 / Prompt Structure

Struktur prompt memengaruhi output.

Prompt yang jelas biasanya memiliki beberapa elemen dasar: konteks, tujuan, format output, batasan, dan contoh ketika diperlukan.

  • 01 Konteks. Jelaskan situasi yang sedang dikerjakan model.
  • 02 Tujuan. Berikan hasil akhir yang ingin diperoleh secara spesifik.
  • 03 Format. Tentukan apakah hasil berupa tabel, teks, JSON, kode, atau format lain.
  • 04 Constraints. Tambahkan batas panjang, gaya bahasa, maupun persyaratan penting lainnya.
03 / Model Behavior

Model berbeda, perilakunya juga berbeda.

Prompt yang bekerja pada satu model belum tentu menghasilkan respons identik pada model lain. Perbedaan data training, alignment, context window, reasoning system, dan konfigurasi produk memengaruhi hasil.

Roleplay & framing

Memberikan persona atau situasi tertentu dapat memengaruhi gaya bahasa dan sudut pandang model. Teknik ini sering digunakan untuk simulasi karakter, penulisan kreatif, maupun eksperimen perilaku model.

Multi-turn context

Percakapan panjang juga memengaruhi respons. Model perlu mempertahankan konteks dari pesan-pesan sebelumnya, sehingga instruksi yang muncul lebih awal dapat berinteraksi dengan instruksi baru.

04 / Alignment

Kenapa model punya batasan?

Model modern biasanya melewati proses alignment dan evaluasi tambahan agar lebih berguna, konsisten, dan aman ketika digunakan dalam berbagai kondisi.

Karena bahasa manusia sangat fleksibel, sistem tersebut terus diuji menggunakan berbagai bentuk prompt, konteks panjang, instruksi bertentangan, dan adversarial evaluation.

Mempelajari perilaku model paling berguna ketika hasil eksperimen dicatat: model, versi, prompt, konfigurasi, respons, dan tanggal pengujian.
